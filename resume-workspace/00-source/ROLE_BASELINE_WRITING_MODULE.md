# Role Baseline Writing Module

状态：ACTIVE。适用于 R1、R2、R3 及后续岗位族基线简历。

## Core invariant

`ROLE FOCUS ≠ EXPERIENCE DELETION`。

岗位方向只控制 Summary、Bullet 强调、每段经历的要点数量、项目先后和 Skills 强调。岗位方向不得改变公司数量、公司名称、岗位路径、起止月份、时间顺序或完整职业时间轴。

所有岗位族简历固定保留：Header、Target Role、Professional Summary、Core Competencies、Work Experience（人瑞 → 今宜 → 朗臻）、Selected Project、Education，以及必要时的 Tools / Additional Skills。三段工作经历必须同时存在。

## R1 Agent Eval focus

职业主线：

`Data Agent Eval → Query / Recall / Relevance → QA / Badcase → SOP / Quality Governance → Search / E-commerce Context → Agent Eval Practice`

- 人瑞是主经历，建议 4–5 条 Bullet，突出 Data Agent、Query、Recall、Relevance、QA、Badcase、争议、SOP、任务规模、一致性和指标观察。
- 今宜保留 2–3 条 Bullet，突出 CTR/CVR/ROI、数据复盘、SOP、多角色协作、KOC 分层和从数据发现问题后调整执行。
- 朗臻保留 2–3 条 Bullet，突出搜索热词、长尾词、商品标题、商品属性、搜索排名、曝光、点击、流量和经营数据。
- 职业叙事应呈现：朗臻的电商搜索/商品/用户意图 → 今宜的数据复盘/业务结果 → 人瑞的 Query/Recall/Relevance/QA/Badcase → Agent 项目的 Eval/Test/Acceptance。

## Role-family emphasis

固定顺序为人瑞 → 今宜 → 朗臻；不同版本只改变内容权重：

| role family | Renrui | Jinyi | Langzhen | Agent project |
|---|---:|---:|---:|---:|
| R1 Agent Eval | 45%–50% | 15%–20% | 15%–20% | 15%–20% |
| R2 Business FDE | 25%–30% | 20%–25% | 20%–25% | 25%–30% |
| R3 AI Commerce | 25%–30% | 25%–30% | 30%–35% | 10%–15% |

权重改变强调程度，不改变是否保留经历。

## Prohibited changes

禁止因岗位方向删除人瑞、今宜、朗臻或 Agent 项目；禁止把旧经历压缩成“其他经历”；禁止用项目替代真实工作经历；禁止为了匹配岗位修改公司、岗位路径、日期、时间顺序或完整职业时间轴。

## Acceptance criteria

岗位族简历必须同时满足：招聘方能快速看懂目标岗位；招聘方能看到完整职业发展路径；三家公司全部保留；不同版本只改变强调内容；候选人实际做过的事情不被改写。

`DIFFERENT EMPHASIS · SAME FACTS · SAME TIMELINE · FULL CAREER HISTORY`
