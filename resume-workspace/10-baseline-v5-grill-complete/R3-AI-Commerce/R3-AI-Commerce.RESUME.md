## 工作经历

### 杭州人瑞网络科技有限公司｜评测专家（淘天 Data Agent）｜2025.09–2026.06

- **电商 Query / 相关性：** 参与 Data Agent 的 Query、召回结果、商品相关性和 Agent 输出评测，将用户搜索意图、商品语义及业务规则落实到具体 Case 判断。
- **搜索链路：** 接触 Query Understanding / Rewrite、召回、Filter、排序、SERP 和反馈链路，并使用 L1/L2/L3 判断商品与需求的匹配程度。
- **Bad Case / 规则治理：** 对判断分歧区分业务上下文、规则边界和执行理解等问题，再推动判断口径持续收敛。
- **质量结果：** 单项任务下游 BPO **10+ 人**；部分任务一致性约 **80%→95%**，复杂任务约 **60%→85%**。
- **版本效果 / A/B：** 参与灰度 / A/B 和数据取数，结合 DAU、CTR、转化和业务水位观察版本效果。

### 杭州今宜商贸有限公司｜抖音项目代运营｜2024.11–2025.07

- **新盘 0→1：** 进入新盘后先判断内容、直播承接和流量链路的关键问题，再决定资源投入；同一账号月 GMV 从早期约 **7 万提升至接手首月约 43 万**。
- **内容运营：** 围绕目标用户、核心卖点和使用场景设计内容表达，通过短视频数据验证后迁移到直播，并参与双机位方案设计。
- **千川投流：** 本人直接使用巨量千川，根据 CTR、CVR、ROI、素材和直播承接判断问题位于内容、流量匹配还是后端转化。
- **数据诊断：** 多个变量同时变化时统一数据口径，通过素材、主播和执行方案对比缩小问题范围，避免依赖单一指标下结论。
- **达人 BD：** 新盘缺乏历史销量和成熟素材时直接开发达人，相关达人合作单月销售额合计 **10 万元+**。
- **项目推进：** 协同约 **6 人直播团队**推进策略、排期、内容、主播、投流和复盘。

### 浙江朗臻网络科技有限公司｜电商运营 → 宠物项目运营管理｜2022.03–2024.07

- **项目运营管理：** 从牙膏品类电商运营起步，2022 年牙膏品类 GMV 约 **300 万+**；后逐步承担项目管理，负责约 **5 个跨平台店铺**的 GMV、利润率、DSR、月 / 季目标和渠道结果，年度整体 GMV 约 **1,500 万**。
- **搜索增长 / SEO：** 从细分搜索需求切入，通过关键词、标题和详情属性优化商品与用户需求匹配，推动核心商品搜索排名由百名外进入 **细分类目前 10**；另一核心 SKU 接手首月内日 GMV 约 **1,000+→15,000+**。
- **市场 / 用户判断：** 将市场、搜索和经营数据用于判断整体机会，同时通过消费者沟通补充真实使用场景和潜在需求，不把少量反馈直接等同于市场结论。
- **小红书运营：** 负责小红书策略和运营管理，协同约 **5 人团队**执行，通过选题、内容测试、有效方向复刻和数据迭代持续优化内容方法。
- **平台商务：** 直接参与京东小二合同、毛利、活动资源和合作方式讨论，在平台资源、推广投入与商家利润之间做实际取舍。
- **供应链 / 项目推进：** 参与销量预估、备货、供应排期、入出库、尾货处理及爆单后的跨仓调拨，并协同内容、客服、供应链、品牌、平台和工厂推进经营事项。
