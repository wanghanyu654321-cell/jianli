## 工作经历

### 杭州人瑞网络科技有限公司｜评测专家（淘天搜推侧 Data Agent）｜2025.09–2026.06

- **搜推侧 Data Agent 评测：** 参与 Query、Data Agent / Agent 输出、召回结果和商品相关性评测，将用户意图、商品语义和业务规则落实到具体 Case 判断，同时关注最终结果是否真正解决用户问题。
- **搜索 Query / 链路理解：** 接触 Query 预处理 / 理解 / Rewrite、Recall、Filter、排序、SERP 与 Feedback 链路，并使用 **L1/L2/L3** 相关性分级判断商品与用户需求的匹配程度。
- **版本效果 / A/B：** 参与执行层灰度桶 / A/B 测试及相关取数，结合 **DAU、CTR、转化、业务水位**观察版本变化、异常和业务结果，为后续问题定位提供输入。
- **Bad Case / 质量判断：** 对重复偏差结合 Query、商品语义、业务上下文、规则边界和执行理解判断问题来源，再通过补充背景、收敛规则、增加案例或调整执行方式进行改善。
- **QA / 规则治理：** 常规承担约 **10% 抽检**，单项任务下游 BPO **10+ 人**；累计参与沉淀 **10+ 份 SOP / 规则 / 执行文档**，部分任务一致性约 **80%→95%**、复杂任务约 **60%→85%**。
