# Interview Workspace

本目录用于沉淀真实面试问题、公开面经问题、当前回答能力与学习缺口。

## 规则

1. 原题与项目事实分离：面试题出现某技术，不代表 `-agent` 已实现该技术。
2. 当前项目事实优先以 `wanghanyu654321-cell/-agent` 当前 main / 对应证据分支为准。
3. 任何示例数字、网上经验值、模板百分比不得直接写入简历或回答，必须替换为可复现的真实结果。
4. 回答分为三档：
   - **P0 直接防守**：当前项目/经历已有真实证据，优先掌握。
   - **P1 JD 防守**：市场高频但当前工程未完整实现，学习后可讲设计与取舍，不可说“做过”。
   - **P2 专项/他人项目题**：特定技术栈或高级分布式题，作为后续专项，不打断当前 POC 主线。
5. 每次真实面试后，把“原题—现场回答—追问—暴露缺口—复测状态”追加到状态文件。

## 文件

- `CORE_100_INTERVIEW_QUESTIONS.md`：核心 100 题主训练集，含来源簇、模块、当前状态与项目证据边界。
- `INTERVIEW_QUESTION_BANK.md`：扩展问题池，按主题去重整理。
- `INTERVIEW_GAP_MAP.md`：问题 → 当前项目/学习计划映射。
- `INTERVIEW_STATUS.md`：当前准备度与下一步。
