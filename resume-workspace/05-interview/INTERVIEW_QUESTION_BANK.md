# Interview Question Bank

更新时间：2026-09-24  
来源：用户提供的真实面试题、公开面经与评测经验帖混合素材。这里保留问题主题，不把外部示例数字当作个人项目事实。

## A. 项目总览 / Agent Architecture（Agent 架构）

- 整体介绍项目；为什么选某个 Agent 框架；工作流怎样？
- Agent Loop（Agent 循环）如何设计？
- 当前项目的具体架构、子模块和工作流是什么？
- 当前项目和上一个项目除了技术栈外，本质区别是什么？
- 最大收获、最大困难、如何解决？
- 单 Agent 和 Multi-Agent（多智能体）为什么这样选？是否做过对照评测？
- Runtime（运行时）适配时，事件如何适配？除了事件还需适配什么？
- Workflow（工作流）为什么改为 Agent + Skill？质量准出与重试如何设计？
- 多花时间换准确率时，如何做质量/性能权衡？

## B. Eval / Benchmark / Harness（评测、基准、执行框架）

- 评测针对什么场景？目标是什么？
- 评测集怎么构建？题目、GT/真值、评分点怎么设计？
- 如何保证覆盖度、可用性、难度分层与边界场景？
- AI 生成评测数据时，如何保证引用文档/案例正确？
- 文档与案例数据如何组织后生成 Case？
- 黄金集 Badcase（坏例）需要人工裁决时怎么处理？
- 人工归因标准是什么？如何把归因自动化？
- Case 错误率、回归结果、重复运行稳定性怎么统计？
- 结果层、过程层、稳定性、成本、健壮性分别看什么指标？
- 哪个指标最能衡量系统达成业务目标？为什么？
- 为什么某些场景不采用自动化评测？
- LLM-as-a-Judge（大模型裁判）如何校准？如何人工抽检？
- 了解哪些 Agent Benchmark / Eval 项目？
- 从零构建缺陷修复 Benchmark 怎么设计？
- 如果做“评测集生成 + 更新维护”调研，最快交付什么？
- 海量线上 Log 如何转成有限离线评测集？为什么不能只随机抽样？
- 能否不转线下 GT，直接对线上 Case 做无 GT 观测？如何推进？
- Badcase 如何回流成 Regression（回归）集？
- 如何做消融实验并同时比较质量、稳定性、Token 与延迟？

## C. RAG / Knowledge / Retrieval（知识库与检索）

- 知识库如何构建？Markdown/TXT/PDF 如何解析和切块？
- Chunk Size（分块大小）依据是什么？如何评估切分策略？
- 纯向量检索的短板是什么？BM25 补什么？
- 为什么同时使用 BM25 和向量检索？
- 两路召回如何融合？
- RRF（Reciprocal Rank Fusion，倒数排名融合）原理是什么？
- 为什么不直接融合 BM25 和向量的原始分数？
- 粗排后为什么使用 Cross-Encoder（交叉编码器）重排？
- Cross-Encoder 为什么比向量相似度更精确？
- 预训练 reranker（重排器）与业务目标不一致时如何验证效果？
- 多种检索方式分别是什么，为什么需要多种？
- 举例说明 Hybrid Retrieval（混合检索）的优势。
- RAG 评测看哪些指标？Context Recall / Faithfulness 等怎么选？
- 动态知识库：知识来源、定时/事件更新、质量治理、实际采纳效果如何评测？
- 关系库与向量库如何分工？
- Milvus 架构是什么？维护的是原始文件、内容还是索引？

## D. Query Understanding / User Input（查询理解）

- 用户问题口语化、错别字、歧义、意图不明确怎么处理？
- 什么时候 Rewrite（改写），什么时候 Clarification（追问澄清）？
- 如何避免 Query Rewrite 改变用户原始意图？
- 多轮上下文对检索 Query 怎么影响？

## E. Safety / Permission / Failure Recovery（安全、权限、失败恢复）

- 云端 Agent 输出如何做安全校验？
- 内容安全评测指标与评测集如何构建？
- Tool 权限、危险动作、人工确认怎样设计？
- Agent 失败/工具超时/外部服务结果不确定时如何处理？
- 子 Agent 重试达到上限后怎么办？
- 人工确认长期不处理时，超时策略是什么？
- 失败恢复、权限安全、成本延迟如何共同进入验收标准？

## F. Session / Context / Memory / Skill（会话、上下文、记忆、技能）

- 会话恢复采用什么方式？

- 会话上下文如何分层？
- 长短期记忆如何划分、分别存哪里？
- Agent Memory（记忆）如何管理？
- 超长对话如何压缩？
- Claude / CodeBuddy 的上下文压缩差异是什么？
- 配置与会话数据放目录是否有泄露风险？
- Trace（链路追踪）放在哪里？
- Agent 交付物如何管理？

## 外部经验帖内容的使用边界

以下内容只能作为“构建评测闭环的启发”，不能直接当作个人项目事实：
- “30 条及格、50–80 条很能打”
- “5:3:2 基础/绕弯/刁难题”
- 示例中的 72%→91%、18%→5%、78%→95% 等百分比
- “每题跑 5 次”等固定次数

真正回答和简历数字必须来自自己项目的可复现实验与保留证据。
